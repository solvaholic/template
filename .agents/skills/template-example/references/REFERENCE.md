# Reference: Hello World

This file demonstrates a `references/` document. An agent loads it on
demand when SKILL.md tells it to.

## What goes here

- Background material the agent reads, not executes
- Domain knowledge, schemas, lookup tables, error catalogs
- Anything too detailed to belong in SKILL.md itself

## Example fact

A traditional first program prints `Hello, World!` to standard output.
Brian Kernighan introduced it in the 1972 Bell Labs tutorial for the B
programming language.
